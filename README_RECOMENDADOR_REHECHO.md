# Prelude · Recomendador rehecho

Esta versión parte de una copia limpia de Prelude y añade únicamente el asesor olfativo.

- Un único sistema de control para todos los botones.
- 4 preguntas.
- 23 perfiles olfativos internos.
- Exclusión de perfumes no publicados o agotados cuando esas funciones están disponibles.
- Resultado principal con fotografía real del catálogo.
- Dos alternativas con fotografía real del catálogo.
- Botón "Descubrir esta fragancia" que abre la ficha/viaje del perfume.

No se han arrastrado los parches de eventos de las versiones anteriores del recomendador.
