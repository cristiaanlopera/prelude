# Prelude Sets · catálogo visual

Cambio principal:
The Five ya no utiliza cinco desplegables de texto.

Ahora el cliente ve:
- catálogo completo disponible para Sets,
- fotografía real de cada perfume,
- nombre y marca,
- precio de 2 ml,
- selección visual,
- contador 0/5,
- límite máximo de cinco fragancias,
- resumen de precio y ahorro cuando completa las cinco.

Solo aparecen perfumes publicados, con precio de 2 ml y con stock suficiente.
No se modifica la lógica de Supabase, carrito ni bonus de Marcapáginas.
