# Catálogo: Próximamente y ordenación

1. Ejecuta `Prelude_Catalogo_Proximamente_Ordenacion.sql` una sola vez en Supabase.
2. Publica después el proyecto en GitHub/Netlify.
3. En Studio > Catálogo cada perfume puede estar **Publicado**, **Próximamente** u **Oculto**.
4. Los perfumes **Próximamente** aparecen siempre al principio de la web con una capa oscura y no se pueden comprar.
5. El cliente puede ordenar los perfumes disponibles por precio, marca o nombre; los próximos lanzamientos permanecen siempre arriba.
