Prelude Sets · volver al catálogo

Al añadir cualquier Set a la cesta:
- se añade el Set;
- se limpia la selección interna;
- se vacía el contenido del popup;
- se reinicia el contador;
- se cierra el modal;
- se hace scroll suave al catálogo principal.

The Five también se abre siempre con una selección limpia.
