# Prelude Studio · Recomendador dentro de Colección

El recomendador ya no tiene una pestaña independiente.

Ruta:
Prelude Studio → Colección → Catálogo → perfume → Perfil del recomendador

Cada perfume muestra:
- Perfil configurado / Perfil pendiente.
- Botón "Perfil del recomendador".
- Controles 1–5 desplegables dentro de la propia ficha.
- Guardar perfil.
- Quitar del recomendador.

El SQL dinámico incluido en la versión anterior sigue siendo necesario si aún no se ha ejecutado.
