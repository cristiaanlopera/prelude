# Prelude Sets · Studio Simulator
Añadido un apartado Prelude Sets a Studio.
- 5 Sets.
- descuento y marcapáginas editables en simulación.
- 5 perfumes seleccionables por Set.
- usa precios actuales de 2 ml del catálogo.
- consulta el coste directo de 2 ml desde el sistema actual de Rentabilidad.
- calcula precio individual, precio Set, beneficio y margen.
- margen mínimo configurable (30 % por defecto).
- The Five y The Match se identifican como dinámicos.
No persiste configuraciones ni conecta todavía los Sets al carrito/Supabase.
