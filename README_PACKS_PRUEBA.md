# Packs Prelude — prueba visual

Se ha añadido una sección de prueba con:
- Your Prelude: 3 × 2 ml, descuento visual 5 %
- Prelude Match: 3 × 2 ml, descuento visual 7 %
- From Day to Night: 3 × 2 ml, descuento visual 6 %
- The Podium: 3 × 2 ml, descuento visual 5 %

IMPORTANTE:
Los porcentajes son provisionales y sirven para valorar la presentación.
No se han conectado aún los packs al carrito ni se han fijado precios definitivos.

Para producción, el precio debe calcularse con:
coste del perfume consumido + envases/etiquetas + otros costes variables,
y comprobar que el margen resultante no baje del mínimo deseado.
