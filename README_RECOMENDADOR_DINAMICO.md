# Prelude · Recomendador dinámico

1. Ejecuta `Prelude_Recomendador_Dinamico_Studio.sql` en Supabase.
2. Sube esta versión a Netlify.
3. Abre Prelude Studio → Recomendador.
4. Los perfumes con ✓ ya tienen perfil. Los que tengan ○ están pendientes.
5. Configura cualquier perfume nuevo con valores del 1 al 5 y pulsa Guardar perfil.

El recomendador público lee esos perfiles desde Supabase y deja de depender de una lista fija de 23 perfumes.
