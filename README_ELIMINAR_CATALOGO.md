# Eliminar perfumes desde Prelude Studio

Esta versión añade **Eliminar** en `Studio → Catálogo`.

Antes de publicar, ejecuta una vez `Prelude_Catalogo_Eliminar_Perfume.sql` en Supabase.

La eliminación es lógica: el perfume desaparece de Prelude Studio y de la web de clientes, pero no se borran pedidos históricos. Esto evita perder trazabilidad comercial.
