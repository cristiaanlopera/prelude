# Prelude Studio · Fase 5

Incluye de forma acumulativa las fases anteriores y activa:

- Recompensas: edición de hitos de Marcapáginas, textos, orden y activación.
- Códigos Prelude: gestión existente, incluida eliminación de códigos de prueba.
- Ranking: se mantiene conectado a las colecciones reales.
- Museo Olfativo: edición de descripción, ruta de la acuarela y publicación/ocultación.
- La web pública lee automáticamente los textos/rutas publicados del Museo y los hitos activos de recompensas desde Supabase.

Ejecuta una sola vez `Prelude_Studio_Fase5_Recompensas_Ranking_Museo.sql` en Supabase antes de publicar.

Nota: Studio puede cambiar la ruta de una obra, pero el archivo de imagen debe existir en GitHub/Netlify. No se guardan credenciales de GitHub en el navegador.
